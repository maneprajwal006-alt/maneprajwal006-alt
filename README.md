## About

I'm two years into a CSE degree, spending most of my free time on the full-stack side of web dev — React on the front, Node/Express/MongoDB on the back — with C and C++ as the languages that taught me how things actually work underneath. Lately I've been pulling AI/ML and API integration into my projects, mostly by building small tools that solve one specific, slightly annoying problem.
